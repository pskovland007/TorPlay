# TorPlay — Android TV (Этап 1)

Минималистичное Android TV приложение для поиска раздач и мгновенного просмотра через **TorrServe MatriX** и **MX Player** (создано для Xiaomi Mi Box, Android 9+, управление с пульта).

## Что работает в Этапе 1
- Экран поиска под пульт (D-pad навигация, подсветка фокуса).
- Проверка статуса TorrServe (`/echo`) и автоматическая попытка запуска сервиса при нажатии.
- Поиск раздач через публичные зеркала **JacRed** с автоматическим переключением на резервный прямой парсер **Rutor**.
- Поддержка своего адреса TorrServe и своего сервера JacRed/Jackett в диалоге настроек.
- Передача раздачи в TorrServe и запуск видеопотока сразу в **MX Player** (с резервом на другие установленные плееры).

## Как собрать APK через GitHub Actions
1. Загрузите содержимое архива в корень нового репозитория на GitHub (ветка `main`).
2. Откройте вкладку **Actions** — сборка запустится автоматически (~1–2 минуты).
3. После завершения откройте раздел **Releases** справа и скачайте готовый `TorPlay-v0.1.0-stage1.apk`.
